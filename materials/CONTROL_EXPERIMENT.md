# 普通大模型与隙见对照实验

## 实验设计

- A 组：把同一批匿名评论直接交给普通大模型，要求生成 6 个选题和 3 份内容方案。
- B 组：使用隙见完成清洗、信号识别、机会排序、证据回溯和 Brief 生成。
- 两组不得访问评论之外的品牌、销量或实验信息。
- 由至少 2 名内容运营盲评，不告知方案来源。

## 评价指标

| 指标 | 记录方式 |
|---|---|
| 完成时间 | 从输入数据到得到 3 份可评方案 |
| 信号识别准确率 | 与人工标注结果比较 |
| 选题与评论匹配度 | 1-5 分 |
| 证据完整度 | 能否给出真实评论 ID 与原文 |
| 运营采用意愿 | 采用 / 修改后采用 / 不采用 |
| 结论信任度 | 1-5 分 |
