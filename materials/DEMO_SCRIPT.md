# 隙见 3 分钟演示脚本

## 0:00-0:30 问题

内容运营每天面对大量零散评论。普通做法能快速生成一些标题，却很难回答：为什么先做这个选题，这个判断来自哪些真实用户表达？

## 0:30-1:00 产品定位

隙见是一款基于真实评论证据的内容机会发现工具。它识别需求矛盾、高频疑问、观点分歧、对比需求和隐藏场景，并用程序计算的“隙值”表示选题优先级。隙值不是爆款预测。

## 1:00-1:45 核心流程

点击“体验无糖饮料示例”，系统读取匿名评论并展示原始、去重、有效和无效数量。读取预计算结果后，页面得到 6 个正式内容机会和 4 个低频弱信号。机会默认按隙值排序，也可以按评论数、信号和优先级筛选。

## 1:45-2:20 证据链

打开“看懂代糖安全与甜味”。五维评分的每一项都有依据，11 条关联评论可以按强表达、高频疑问、不同观点和高赞筛选。页面不展示用户名或主页，每个洞察都能回到匿名评论 ID。

## 2:20-2:50 Brief

点击“生成内容 Brief”。系统给出疑虑破除、观点验证和场景解决三份不同方案，每份包含标题、人群、钩子、结构、观点、风险提示和至少 3 条真实评论证据。方案可单独重生成、复制并导出 Markdown。

## 2:50-3:00 总结

隙见不是替运营凭空想标题，而是从真实评论中证明下一个选题为什么值得做。

## 演示兜底

- 无 API Key：读取无糖饮料预计算结果和 18 份预生成 Brief。
- 网络异常：继续展示本地保存的任务、证据和导出能力。
- 时间不足：从首页直接加载示例，读取预计算结果，不运行实时分析。
